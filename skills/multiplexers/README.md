# Multiplexers

Skills for driving terminal multiplexers and agent workspaces.

- **[delegate](./delegate/SKILL.md)**: Delegation policy inside any terminal multiplexer or agent workspace: a visible pane per subagent, an English brief, a model matched to the task class (research, reasoning, execution, review), event hooks for follow-up skills or subagents, and a close gate on verified completion.
- **[run-in-pane](./run-in-pane/SKILL.md)**: Run dev servers, studios, watchers and other long-running processes in visible, titled panes instead of the background.
