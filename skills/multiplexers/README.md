# Multiplexers

Skills for driving terminal multiplexers and agent workspaces.

- **[delegate](./delegate/SKILL.md)**: Run a subagent in its own visible multiplexer pane with an English brief, a model matched to the task class (research, reasoning, execution, review), event hooks and a close gate on verified completion. Invoked by name, never by the agent on its own.
- **[run-in-pane](./run-in-pane/SKILL.md)**: Start dev servers, watchers, tunnels and other commands that keep running in visible, titled panes the user can watch and stop, instead of the background. Works in any terminal tool through adapter files.
