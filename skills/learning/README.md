# Learning

Skills that align agents with how the user works, so the same correction is never needed twice.

- **[autolearn](./autolearn/SKILL.md)**: Private, per-project notes on how agents should work for you, learned from corrections, rewrites and confirmations, loaded at the start of every session.
- **[dreaming](./dreaming/SKILL.md)**: Study recent sessions across projects and agents, and distil a working profile every agent loads. Runs weekly.
